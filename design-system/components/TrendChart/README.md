# TrendChart

单一指标的趋势柱状图：商家端近 7 日营业额、管理端近 14 日 GMV。

**提供**：`data`（`[{label, value}]`）、可选 `title`、`subtitle`（写单位）、`height`（默认 240）、`prefix` / `unit`（悬停提示里的完整数值）、`tickFormat`（纵轴刻度，默认中文缩写：万、亿）、`valueFormat`。

- 只画一个指标，柱子 `brand`、最宽 24px、顶部 4px 圆角；网格线 `line`，刻度与标签 `ink-muted`，文字从不用柱子的颜色。
- 只在最后一根柱上标数值；其余数值在鼠标悬停 / 键盘聚焦的提示里，并附一份读屏用的数据表。
- 一张图一个纵轴。要对比两个量（营业额与订单量）就画两张图。
- 单一系列不需要图例，标题已经说明画的是什么。
