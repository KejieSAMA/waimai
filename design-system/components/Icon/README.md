# Icon

24px 网格的线性图标，线宽 1.75px，颜色继承父元素的 `color`。

**提供**：`name`（见下表）、`size`（默认 20）、可选 `title`（图标单独表达含义时作为无障碍名称）。`Icon.names` 列出全部名称。

| 场景 | 尺寸 | 颜色 |
|---|---|---|
| 底部 Tab、导航栏 | 22 | 继承（`ink-muted` / `brand-text` / `on-chrome`） |
| 列表行、按钮内 | 16–20 | `ink-muted` 或继承按钮文字色 |
| 卡片内小图标 | 12–16 | 继承 |

- 图标旁边要有文字。只有导航栏的“返回”“更多”“消息”可以单独出现，并且必须传 `aria-label`（`NavBar.Icon` 已处理）。
- `star` 是唯一的实心图标，只用于评分，填 `accent`。
- `bowl` 是图片占位专用，不要拿来当“美食”分类图标。
- 这是一套为小灶绘制的临时图标，换成正式图标库时保持 24 网格与 1.75 线宽。
