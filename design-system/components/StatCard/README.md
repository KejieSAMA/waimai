# StatCard

一个核心数字加环比，用于商家端工作台和管理端总览。

**提供**：`label`（带单位：“今日营业额（元）”）、`value`（已格式化的字符串，金额两位小数加千分位）、可选 `unit`（“单”“家”）、`delta`（百分比数字，正负决定 ↑ ↓）、`deltaLabel`（默认“较昨日”）、`icon`、`tone`、`size`（`sm` 用于两列网格）。

| tone | 用于 |
|---|---|
| `plain` | 默认，白卡片 |
| `brand` | 商家端工作台最顶部的一张（今日营业额） |
| `chrome` | 管理端总览最顶部的一张（平台 GMV） |

- 每页最多一张 `brand` 或 `chrome`，其余用 `plain`。
- 上升 / 下降同时用箭头和颜色（`success` / `danger`）表示；`brand`、`chrome` 卡片上只靠箭头，文字保持 `on-brand` / `on-chrome`。
- 退款、投诉这类“越少越好”的指标，下降仍然显示 `danger` 色的 ↓——颜色只表示方向，不表示好坏。
