# 三端信息架构

三端各管一层：管理端管“商家能不能在平台上做生意”，商家端管“自己店里卖什么、怎么卖”，用户端管“买”。下面的权限、页面和状态流转是组件和页面设计的依据；改动业务规则时先改这里。

## 权限分工

| 能力 | 管理端 | 商家端 | 用户端 |
|---|---|---|---|
| 商家入驻 | 审核：通过 / 驳回（填原因） | 提交资料、查看审核进度 | — |
| 商家状态 | 冻结 / 解冻 | 营业 / 休息（自主切换） | 看到“休息中”，不能下单 |
| 店铺信息 | 查看 | 编辑名称、Logo、公告、营业时间、起送价、配送费 | 查看 |
| 商品 | 查看、强制下架违规商品 | 新增、编辑、上架、下架、改库存 | 浏览、搜索、加购物车 |
| 商品审核（可选） | 审核新商品与改价 | 提交后显示“审核中” | 只看到“在售”的商品 |
| 订单 | 全平台查看、介入退款纠纷 | 接单 / 拒单、出餐、处理退款 | 下单、支付、取消、申请退款、评价 |
| 数据 | 平台 GMV、订单量、商家数、待办 | 本店营业额、订单量、商品销量 | 自己的订单记录 |
| 类目 | 维护平台类目 | 选择类目 | 按类目筛选 |

## 各端页面

### 用户端（底部 Tab：首页 / 订单 / 我的）

- **首页**：搜索、类目筛选（`Tabs variant="chip"`）、附近店铺列表（`StoreCard`）。
- **店铺点餐**：店铺信息、左侧分类（`CategoryNav`）+ 右侧菜品（`DishCard`）、底部购物车栏（`CartBar`）。
- **订单**：按状态筛选的订单列表（`OrderCard view="user"`）。
- 其余页面（沿用同一组件）：搜索结果、菜品详情、确认订单、支付结果、订单详情、评价、地址管理、我的。

### 商家端（底部 Tab：工作台 / 订单 / 商品 / 我的）

- **工作台**：营业开关（`Switch`）、今日数据（`StatCard`）、待处理事项、快捷入口。
- **订单**：新订单 / 备餐中 / 配送中 / 退款分 Tab，卡片上直接接单、出餐（`OrderCard view="merchant"`）。
- **商品管理**：在售 / 已下架 / 审核中分 Tab，每行带上下架开关和编辑（`ProductRow`），右下角“新增商品”。
- **商品编辑**：图片、名称、分类、价格、库存、描述；底部“保存并上架”。
- 其余页面：店铺设置、营业时间、经营数据、评价管理、账户与结算。

### 管理端（底部 Tab：总览 / 商家 / 审核 / 我的）

- **数据总览**：平台 GMV、订单量、在营商家数、待审核数（`StatCard`），待办列表。
- **商家管理**：全部 / 待审核 / 营业中 / 已冻结分 Tab，搜索，`MerchantRow` 列表，行内冻结 / 解冻。
- **商家审核**：资料详情（店铺信息、营业执照、食品经营许可证、负责人），底部“驳回”“通过”。
- 其余页面：商品巡检、订单监管、退款纠纷、类目管理、平台公告、账号与权限。

## 桌面版页面

三端的桌面版与手机版功能相同，入口一一对应；桌面版把列表换成表格、把状态 Tab 展开成看板，并多出手机上放不下的二级入口。

### 用户端网页（顶栏导航：首页 / 我的订单）

- **首页**：类目（`Tabs variant="chip"`）、排序与快捷筛选、附近商家三列（`StoreCard`）。
- **店铺点餐**：店铺信息、点菜 / 评价 / 商家，左侧分类、中间菜品两列、右侧购物车（`CartPanel`）。
- **我的订单**：左侧账号导航（`SideNav brand={false}`），右侧订单两列（`OrderCard view="user"`）。

### 商家端后台（侧栏：工作台 / 订单 / 商品管理 · 经营 · 店铺）

- **工作台**：今日数据（`StatCard`）、近 7 日营业额（`TrendChart`）、待处理、新订单三列。
- **订单看板**：新订单 / 备餐中 / 配送中 / 退款四列，卡片上直接接单、出餐、处理退款。
- **商品管理**：状态 Tab + `FilterBar` + `DataTable`（上架开关、库存预警、批量下架、批量改库存）。
- **新增 / 编辑商品**：左侧表单，右侧用户端预览与上架设置，保存按钮在 `PageHeader`。
- 其余页面：经营数据、评价管理、账户与结算、店铺设置、营业时间。

### 管理端后台（侧栏：数据总览 · 商家 · 交易 · 平台）

- **数据总览**：平台 GMV 与 4 项指标、近 14 日 GMV、待办、今日商家排行表。
- **商家管理**：状态 Tab + `FilterBar` + `DataTable`，行内审核、冻结、解冻。
- **入驻审核**：待审核表格，点“审核”从右侧打开抽屉（`Dialog variant="drawer"`），底部驳回 / 通过。
- 其余页面：商品巡检、订单监管、退款纠纷、类目管理、平台公告、账号与权限。

## 状态流转

### 商家入驻

1. 商家端提交资料 → **待审核**（`warning`）。
2. 管理端审核：通过 → **营业中**（`success`）；驳回 → **已驳回**（`danger`），附原因，商家修改后可重新提交。
3. 营业中的商家可自行切换 **休息中**（中性）；管理端可 **冻结**（`danger`），冻结后店铺对用户不可见，商家端只能查看。

### 商品上下架

1. 商家新增商品 → 平台开启商品审核时为 **审核中**（`info`），否则直接 **在售**（`success`）。
2. 审核驳回 → **审核驳回**（`danger`），行内显示原因，修改后重新提交。
3. 在售商品：商家关掉开关 → **已下架**（中性），弹窗确认“确认下架”；库存降到 0 → 自动 **已售罄**（`warning`），补库存后自动恢复在售。
4. 管理端强制下架的商品，商家端开关禁用，并显示原因。

### 订单

| 状态 | 颜色 | 谁推进 | 下一步 |
|---|---|---|---|
| 待接单 | `brand-text` | 商家：接单 / 拒单 | 备餐中 / 已取消 |
| 备餐中 | `warning` | 商家：出餐 | 配送中 / 待自提 |
| 配送中、待自提 | `info` | 骑手送达 / 用户取餐 | 已完成 |
| 已完成 | `success` | 用户：评价、再来一单 | — |
| 已取消 | 中性 | — | — |
| 退款中 | `danger` | 商家同意 / 拒绝，纠纷时管理端介入 | 已取消 / 已完成 |
