# 小灶外卖平台

Vue 3、Express、Prisma 和 SQLite 构成的 pnpm workspace，包含用户、商家和管理三种角色的 PC 与手机应用。

## 本地启动

使用 Node 22 和 pnpm 10。

```powershell
pnpm install
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
pnpm db:setup
pnpm dev
```

服务默认监听 `0.0.0.0`。PC 端口为 `13599`，手机内部开发端口为 `5174`，API 默认端口为 `3000`。当前电脑的 `3000` 已占用，本地 `.env` 使用 `3001`，开发代理已同步。浏览器统一访问 [用户首页](http://localhost:13599)。局域网设备使用开发电脑的 IP 和 `13599` 端口访问。

| 入口         | PC          | 手机               |
| ------------ | ----------- | ------------------ |
| 用户         | `/`         | `/mobile/`         |
| 商家         | `/merchant` | `/mobile/merchant` |
| 管理         | `/admin`    | `/mobile/admin`    |
| 开发组件画廊 | `/__ui`     | `/mobile/__ui`     |

PC 的 Vite 代理 API、上传文件和整个 `/mobile` 路径。手机 HMR websocket 也经过这个入口。端口被占用时启动会报错，可在 `.env` 修改对应端口。

未手动指定版本时，页面在启动、窗口尺寸变化和页面恢复时自动检测设备：手机设备或宽度小于 768px 时进入对应手机版，其余进入 PC 版。切换保留当前页面、查询参数和锚点，例如 `/store/store-0` 与 `/mobile/store/store-0` 自动对应。手动选择的版本仍优先；开发调试如需恢复自动检测，可在控制台执行 `localStorage.removeItem('xz-device')` 后刷新。

| ---- | ------------- | ------------------------------------- |

| 商家 | `13800000001` | `merchant123`                         |
| 管理 | `admin`       | `admin123`                            |

用户验证码有效期 5 分钟，验证成功后失效。商家登录页提供注册入口，注册后进入入驻申请。演示数据包括营业、休息、冻结和待审核店铺，以及多个订单状态。种子可重复执行，会保留现有业务数据。

## 主要操作

- 用户选择菜品，在结算页选择配送或自提，提交后进入订单详情进行模拟支付。配送中或待自提订单可以确认完成。订单详情提供取消、退款、申诉和评价入口。
- 商家工作台和订单页面可开启提醒。开启时浏览器取得音频播放授权，并建立 SSE 连接。接单后出餐，退款申请可同意或拒绝。
- 商家商品管理提供上下架、库存筛选和编辑。PC 提供批量上下架与改库存。管理员强制下架的商品须修改后重新审核。
- 管理端处理入驻审核、冻结和解冻，进行商品巡检、订单监管、退款裁定和平台类目管理。关键动作写入审计记录。
- 主题支持跟随系统及手动切换。设备切换会保存选择。三种角色分别保存会话，同一浏览器可并行登录。

## 目录

| 目录              | 内容                                                   |
| ----------------- | ------------------------------------------------------ |
| `design-system`   | 原始只读设计规范                                       |
| `packages/tokens` | 原样复制的 token、组件 CSS、本地 Barlow 字体与主题逻辑 |
| `packages/ui`     | 两端共享的 Vue SFC                                     |
| `packages/shared` | 类型、状态映射、格式化与可注入传输层的 API 客户端      |
| `frontend`        | PC 三角色应用                                          |
| `mobile`          | `/mobile/` 手机三角色应用                              |
| `backend`         | 鉴权、业务模块、领域状态机、数据库迁移、种子与测试     |
| `docs`            | 详细规格、计划、决定、检查记录与部署说明               |

API 使用 `/api/v1`，成功响应为 `{ code: 0, message: 'ok', data }`。金额以整数分保存，订单保留价格和地址快照。数据库文件和上传文件已加入 Git 忽略规则。

距离排序需要接入定位坐标，当前首页提供综合、销量和起送价排序。实现决定见 [开发决定](docs/DECISIONS.md)。
