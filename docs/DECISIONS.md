# 开发决定

- 2026-11-11，最新用户要求优先于阶段编译和自动视觉验收条款，本次执行 lint、无产物类型检查及测试，编译和界面验收由用户安排。
- 2026-11-11，所有服务监听 0.0.0.0，PC 端口使用 13599，手机内部端口保留 5174，统一入口保持 PC 代理方式。
- 2026-11-11，SQLite 使用字符串状态并由 zod 与领域状态机约束，方便切换数据库 provider，切换 MySQL 时需更改 provider 并重新生成迁移。
- 2026-11-11，新增订单完成接口和退款申诉接口，补齐 SPEC 中配送完成、自提完成和纠纷介入所需入口。
- 2026-11-11，未接真实短信服务时固定验证码仅在开发环境可用，生产环境需实现 SmsProvider 后启用短信登录。

- 2026-11-11，订单完成与退款申诉分别采用用户端 complete、dispute 接口，以支持现有订单流程的后续动作。
- 2026-11-11，商家拒绝退款后保留退款中状态并标记拒绝，用户申请介入后由管理员裁定，同意则回补库存，拒绝则恢复退款前状态。
- 2026-11-11，证照上传携带 certificate 用途并保存所有者元数据，文件读取要求所有者或管理员的 Bearer 身份，以保护材料访问。
- 2026-11-11，现有数据模型未提供坐标，首页提供综合、销量和起送价排序，距离排序待接入定位数据后实现。
- 2026-11-11，手机浏览器使用真实设备安全区，页面骨架省去预览用模拟时间状态栏。
- 2026-11-11，SQLite 初始化先创建空数据库文件，再部署迁移，解决当前 Windows Prisma 对缺失文件的初始化错误。
- 2026-11-11，事务使用 Serializable 隔离级别，数据库并发冲突返回 409，客户端可刷新后重试。

- 2026-11-11，当前电脑 3000 端口已有服务，本地未提交的 .env 将 API 设为 3001，开发代理随环境变量读取，对外入口保持 13599。

- 2026-11-11，按本次首页调整要求移除 PC 页脚切换区域和顶栏搜索，首页分页固定在视口底部居中；主题切换沿用现有记忆逻辑，浅色显示太阳、深色显示月亮，图标遵循现有 24px 网格与线宽。
- 2026-11-11，商家卡片取消促销与公告行，将休息中文字移至店名旁，配合居中灰色 Logo 保留状态文字表达；应用可见品牌统一为盟信。
- 2026-11-11，PC 购物车在异步报价期间保留上次金额并禁用结算，响应完成后替换金额；数量调整保留商品行顺序，清空、换店和报价失败时清除旧金额。
- 2026-11-11，PC 店铺页左上角复用 back SVG 图标返回商家列表，演示店铺老张家牛肉面的种子商品增加到 24 款，便于人工查看滚动效果。
