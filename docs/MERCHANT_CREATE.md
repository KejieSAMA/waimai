# 管理员直接创建店铺

## 入口与业务规则

PC 商家管理的查询右侧及手机商家管理顶栏增加“创建店铺”，审核列表不显示。创建页为 `/admin/merchants/new`，手机带 `/mobile/` 前缀；PC 保持商家管理选中，手机使用固定底部操作栏。

四组资料为商家账号、基础信息、营业配送及选填资质。独立填写账号名、临时密码、负责人姓名，账号联系手机选填；门店联系电话另存，不自动互相覆盖。账号名规范为小写，长度与字符限制及 8 字符／72 字节密码规则复用正式账号系统。城市与类目初始为空，类目来自真实接口；营业时间、起送价、配送费默认 09:00–22:00、20 元、3 元，可修改。

账号、MERCHANT 唯一初始角色、店铺及两条审计在同一事务创建。账号 ACTIVE、首次登录需改密；店铺 CLOSED、submitCount=0、rating=null、销量为零，不需要再次审核。没有账号选择／绑定动作，也不生成商品、店内分类和优惠。已有账号冲突不能复用或改权。

成功后清空密码并进入新店详情，显示登录账号和首次改密说明。PC 通过 `/admin/merchants?created=店铺ID` 打开现有详情，关闭清理该参数；手机复用 `/admin/audit/:id?from=merchants`，标题为商家详情。直接创建的新店不显示虚假的入驻提交次数，创建时间不标为提交时间。若跳转失败，保存成功结果和查看入口，禁止再次创建。

## API 与事务

`POST /api/v1/admin/merchants`：

```json
{
  "account": {
    "username": "独立账号名",
    "password": "管理员填写的临时密码",
    "name": "负责人姓名",
    "phone": "选填联系手机"
  },
  "store": {
    "name": "店铺名称",
    "categoryId": "真实类目ID",
    "city": "城市",
    "address": "门店地址",
    "contactPhone": "门店联系电话",
    "openHours": "09:00-22:00",
    "minOrderCents": 2000,
    "deliveryFeeCents": 300
  }
}
```

store 同时支持现有 logo、notice、选填证照及日期；全部字段遵循既有校验，额外身份、归属、角色、状态字段拒绝。响应为安全 `{ account, store }`，不返回密码／哈希，创建响应 no-store。账号摘要含 id、username、name、status、roles、mustChangePassword、createdAt。仅管理员当前身份可调用，首次改密未完成不可用。

密码在事务外哈希；事务内再次核验会话、账号状态、管理员授权及类目。复用账号服务的事务创建及店铺服务，审计分别使用 account-create 和 store-create。失败整体回滚，账号唯一约束处理重复及并发；账号冲突 409 携带 `details.reason=USERNAME_TAKEN`；类目失效、错误资质或私有 Logo 的 400 原因分别为 CATEGORY_UNAVAILABLE、INVALID_QUALIFICATION、INVALID_LOGO，用于定位对应表单分组。无数据库迁移、状态机或原入驻流程改变。

前端不自动重试创建。网络断开或服务失败导致结果不明时保留输入，提示先按账号名在账号管理核对，避免换账号名重建。密码只在当前表单内存保存，成功、退出页面和身份失效卸载时清除，不写入 URL、审计、日志或本地存储。

## 资质与上传

证照和日期均选填。图片使用现有管理员私有上传，必须属于当前管理员，普通公开图片及其他上传者证照不能冒充；私有证照不能用作公开 Logo。无对应图片时日期归零。创建后沿用现有资质只读规则，本轮不新增资质变更入口。

上传者旁路元数据保持原样；读取时，管理员、原上传者及 MERCHANT 身份下引用该证照的本店所有者可读取。商家必须先完成改密，其他商家及游客无权读取，未被本店引用的管理员私有文件同样拒绝。不搬移文件、不扩大公开静态资源范围。

## 人工验收

- [ ] 两端商家管理创建入口与审核页入口隐藏；创建页导航、分组切换、固定操作区、矮窗口及窄屏。
- [ ] 类目加载／失败重试／空类目；城市为空；账号和门店电话分别保存。
- [ ] 无／单／双证照、上传预览、失败保留旧图、有效期、深浅主题与键盘操作。
- [ ] 账号重复、弱密码及字段校验定位分组；提交／上传互斥；失败保留输入、离开确认与身份失效安全跳转。
- [ ] 创建后查看新店账号、暂无评分、休息中、无虚构提交次数；首次登录改密后正常进入店铺设置。
- [ ] 商家维护分类和商品、自主营业、用户可见；停用账号或撤销商家身份仍冻结店铺。

自动测试使用完整迁移链的隔离数据库和临时上传目录，不在业务库创建测试店铺。人工视觉验收待执行；不编译、不执行自动 UI 验收。
