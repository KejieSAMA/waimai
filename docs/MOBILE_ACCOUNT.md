# 手机个人中心与设置

本轮仅重组手机用户、商家、管理员的我的页；PC 布局与既有账号权限不变，无数据库迁移。

## 参考与取舍

- [Shopify 账号管理](https://help.shopify.com/en/manual/your-account/manage-account)：将资料与账号安全分组，联系手机与经营资料分开。
- [Shopify 授权切换](https://help.shopify.com/en/manual/your-account/logging-in/store-switcher)：只在授权范围内显示切换对象。本项目切换的是当前角色，继续由服务器决定权限。
- [美团门店管理说明](https://kf.dianping.com/csCenter/app/questions/15437)：从我的进入门店管理。这里沿用现有审核／冻结状态，不新增自动营业能力。

参考用于信息组织，页面外观使用盟信现有 token 与 Vue 组件，不复制其他品牌色彩或添加虚假功能。

## 实现边界

- `MyPage`、`IdentityCard`、`AccountShortcuts`、`RolePicker` 为三端复用的手机展示组合；请求和互斥逻辑在应用控制器及共享会话中。
- `/mobile/settings`、`/mobile/account/profile` 为受保护的当前账号公共路由，使用当前身份顶栏，直接打开后的返回目标为该身份我的；没有业务 Tab。资料保存使用现有 MobilePage 底部插槽和安全区。
- 资料页从 GET /auth/me 读取最新资料，PUT /auth/me 只提交昵称和联系手机；编辑手机不会修改收货地址和店铺电话，也不作为登录验证方式。失败保留草稿，成功采用服务端结果并返回我的。
- 授权角色、账号名只读。身份切换时当前项只关闭 sheet，其他项显式调用原授权接口。切换及退出请求互斥，面板、返回导航在请求期间锁定；身份失效跳转放行。
- 资料更新不轮换正常会话，不广播强制清理其他标签页的业务状态；其他标签页恢复会话时读取最新本人资料。资料响应通过发起账号、角色、请求代次核验，不允许迟到响应覆盖新账号。
- 外观沿用 xz-theme 与 useTheme 的跟随系统／浅色／深色持久化。手机电脑版入口及未引用的手动切换函数删除，既有设备自动路由规则不变。

- [ ] 长昵称与账号名、窄屏换行、点击区域、深浅主题；所有快捷入口均到达对应业务页面。
- [ ] 用户两列订单／地址入口；商家三列快捷入口与单个店铺入口；管理员三列快捷入口及四项管理工具。
- [ ] 商家无店铺、待审核、驳回、营业、休息、冻结状态；加载中无错误状态，失败可重试，冻结仍只读。
- [ ] 单身份为静态胶囊，多身份 sheet 仅列出授权角色；当前项关闭、成功切换、失败重试、切换期间不能重复操作或关闭。
- [ ] 直接访问 settings／profile，顶栏沿用当前身份，返回对应我的，不显示业务 Tab；强制改密仍先进入 password。
- [ ] 资料未修改禁用保存；昵称 1–30 字，手机修改／清空及错误提示；保存时锁定输入，失败保留草稿，成功返回且我的显示新值。
- [ ] 脏草稿离开可继续编辑或放弃；刷新仅脏草稿提示；账号停用／授权变化后不阻挡安全跳转；迟到响应不覆盖新身份。
- [ ] 跟随系统／浅色／深色切换并刷新恢复；退出先确认，失败留在当前会话，成功进入原角色登录页。
- [ ] 固定保存区、页面滚动、手机键盘弹起及底部安全区。
